# GREMLIN - GRavimEtric and Muographic Linear INversion

## Overview

Joint Bayesian inversion of gravimetric and muographic data over a regular grid

## Author

Anne Barnoud - 2016/2020

## Where is the code?

The GREMLIN code is available on Codeberg: https://codeberg.org/barnouda/gremlin
